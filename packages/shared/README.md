# Shared contracts

Здесь будут общие контракты между клиентом и сервером:
- типы и состояния сессий;
- модели устройств и запросов на подключение;
- DTO и схемы валидации;
- события и сообщения протокола.

Не размещать здесь секреты, пользовательские данные или реализацию, привязанную только к одному приложению.
