# Supabase

Supabase выбран для аутентификации, базы данных и пользовательских данных.

Миграции схемы будут размещаться в `migrations/`. До создания таблиц необходимо определить модель пользователей, устройств, сессий и прав доступа, а также подготовить RLS-политики.

Не хранить пользовательские файлы в Git-репозитории.
