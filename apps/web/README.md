# Web application

Здесь будет клиентское веб-приложение Linqor.

Планируемые зоны ответственности:
- регистрация и вход;
- интерфейс QR-подключения и подтверждения;
- экран активной сессии;
- отправка и получение данных;
- просмотр истории сессии;
- скачивание файлов и копирование содержимого.

Стек и команды сборки пока не выбраны. Не добавлять framework-specific конфигурацию до фиксации технологического стека.
