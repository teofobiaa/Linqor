# Edge service

Здесь будет серверный слой Linqor на инфраструктуре Cloudflare.

Планируемые зоны ответственности:
- создание и завершение сессий;
- координация подключения устройств;
- проверка полномочий и доступа;
- обмен событиями между клиентами;
- контроль временных токенов и срока хранения.

Конкретный продукт Cloudflare и модель выполнения пока не выбраны.
