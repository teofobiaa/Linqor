# Структура клиентского приложения

## Платформы
- `apps/web`: React + TypeScript + Vite, браузерный клиент для Windows 10/11.
- `apps/android`: React Native + Expo + TypeScript, Android-клиент.
- `packages/domain`: платформонезависимые доменные типы.
- `packages/protocol`: контракты клиент-серверных и межустройственных сообщений.
- `packages/validation`: схемы проверки входных данных.
- `packages/crypto`: криптографические контракты и интерфейс защищённого хранилища. Production-алгоритмы не реализованы до утверждения криптографической спецификации.

## Клиентские разделы

Оба клиента предусматривают экраны авторизации, подключения устройств, сессии, настроек и избранных бесед. Избранные беседы должны быть доступны после авторизации на устройстве; их синхронизация требует реализации backend.

## Принципы
1. UI не обращается напрямую к БД и не содержит сетевую бизнес-логику.
2. Платформенные адаптеры (камера, secure storage, файловая система, буфер обмена) остаются внутри соответствующих приложений.
3. Общие пакеты не импортируют React, Expo или браузерные API.
4. QR payload содержит только короткоживущий токен подключения, но не пароль, мастер-ключ или содержимое сессии.
5. Секреты и пользовательские данные не коммитятся в Git.
6. Наличие каркаса не означает, что авторизация, транспорт, E2EE или передача файлов уже работают.

## Команды

- `pnpm dev:web`
- `pnpm dev:android`
- `pnpm build`
- `pnpm typecheck`
