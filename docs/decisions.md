# Принятые проектные решения

| Область | Решение | Статус |
| --- | --- | --- |
| Назначение | Мост для обмена данными между двумя устройствами | Зафиксировано |
| Платформы | Web для Windows 10/11 через браузер и Android; iOS и нативный Windows-клиент не входят в первый объём | Зафиксировано |
| Web-стек | React + TypeScript + Vite | Выбрано |
| Android-стек | React Native + Expo + TypeScript | Выбрано |
| Монорепозиторий | pnpm workspaces + Turborepo | Выбрано |
| Общие пакеты | domain, protocol, validation, crypto | Выбрано |
| Подключение | QR-код инициирует подключение | Зафиксировано |
| Подтверждение | Подключение требует подтверждения на уже авторизованном устройстве | Зафиксировано |
| Доступ | Без регистрации функции приложения недоступны | Зафиксировано |
| Сессии | Новое QR-подключение создаёт новую сессию | Зафиксировано |
| Содержимое | Просмотр истории, скачивание файлов и копирование данных | Зафиксировано |
| Пароль архива | Пароль расшифровки E2EE-архива совпадает с паролем входа в Linqor | Зафиксировано |
| Мастер-ключ | После первого ввода пароля клиент расшифровывает мастер-ключ и сохраняет его в защищённом локальном хранилище; на том же устройстве восстановление автоматическое, на новом потребуется пароль | Зафиксировано |
| Хранение | Ограниченный срок; рабочий ориентир — 7 суток | Требует детализации правил |
| Инфраструктура | GitHub + Cloudflare + Supabase + GitHub Actions | Выбрано как направление |
| Данные GitHub | Пользовательские сообщения и файлы не хранятся в репозитории | Зафиксировано |
| Приоритет | Максимально использовать бесплатную инфраструктуру на первом этапе | Зафиксировано |

## Не следует считать решённым

- Конкретные способы входа и UX аутентификации.
- Конкретные продукты Cloudflare.
- P2P, relay или гибридная передача.
- Протокол обмена сообщениями и файлами.
- Конкретные алгоритмы E2EE, KDF, параметры, key wrapping, ротация и восстановление.
- Точная схема БД и RLS.
- Лимиты файлов и пропускной способности.
- Точная семантика удаления данных.
- Поведение при закрытии вкладки и работе приложения в фоне.

Изменение зафиксированного решения требует обновления этого документа и связанной архитектурной документации.
