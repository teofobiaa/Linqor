# Дорожная карта

Порядок этапов предварительный. Переход к следующему этапу — после проверки результатов предыдущего.

## Этап 1. Проектирование

- [ ] Уточнить пользовательские сценарии и границы первой версии.
- [ ] Зафиксировать модель угроз и требования к безопасности.
- [ ] Выбрать стек клиентского приложения.
- [ ] Выбрать конкретные сервисы Cloudflare.
- [ ] Определить схему взаимодействия устройств: P2P, relay или гибрид.
- [ ] Спроектировать модель сессий, данных и сроков хранения.
- [ ] Описать API и протокол обмена.

## Этап 2. Основа приложения

- [ ] Создать клиентское приложение.
- [ ] Настроить серверный слой.
- [ ] Подключить Supabase Auth.
- [ ] Реализовать регистрацию и вход по email/паролю.
- [ ] Реализовать вход и регистрацию через Google OAuth 2.0.
- [ ] Настроить безопасные OAuth callback и разрешённые redirect URL для dev и production.
- [ ] Проверить сценарии повторного входа и связывания идентичностей без дублирования аккаунтов.
- [ ] Подготовить миграции и политики доступа.
- [ ] Настроить окружения и безопасное хранение секретов.
- [ ] Добавить автоматические проверки в GitHub Actions.

## Этап 3. Подключение устройств

- [ ] Реализовать создание запроса на подключение.
- [ ] Реализовать генерацию и проверку QR-кода.
- [ ] Добавить подтверждение на авторизованном устройстве.
- [ ] Реализовать создание и завершение сессии.
- [ ] Проверить повторное использование и истечение QR-токенов.

## Этап 4. Передача данных

- [ ] Реализовать обмен текстовыми данными.
- [ ] Реализовать передачу файлов.
- [ ] Добавить прогресс, отмену и обработку ошибок передачи.
- [ ] Добавить скачивание файлов и копирование содержимого.
- [ ] Проверить восстановление после обрыва соединения.

## Этап 5. Хранение и надёжность

- [ ] Реализовать просмотр сохранённого содержимого сессии.
- [ ] Реализовать автоматическое удаление по сроку хранения.
- [ ] Проверить удаление связанных файлов и метаданных.
- [ ] Добавить лимиты и защиту от злоупотреблений.
- [ ] Провести тестирование безопасности и нагрузки.

## Этап 6. Подготовка к выпуску

- [ ] Подготовить пользовательскую документацию.
- [ ] Настроить мониторинг и журналирование без утечки содержимого.
- [ ] Проверить доступность и поведение на мобильных устройствах.
- [ ] Провести финальную проверку сценариев и ограничений бесплатных тарифов.
- [ ] Подготовить первый релиз.
