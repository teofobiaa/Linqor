# Linqor

**Linqor** — приложение-мост для контролируемого обмена данными между двумя устройствами. Подключение инициируется QR-кодом, а обмен выполняется в отдельной сессии.

> Проект находится на раннем этапе. Репозиторий содержит рабочую основу клиентского монорепозитория и начальные экраны. Авторизация, транспорт, E2EE и передача файлов ещё не реализованы.

## Клиентские платформы

| Платформа | Реализация | Назначение |
| --- | --- | --- |
| Web | React + TypeScript + Vite | Браузер на Windows 10/11 |
| Android | React Native 0.88 + Expo SDK 58 + TypeScript | Мобильное приложение |

iOS и нативный клиент Windows в текущий объём не входят.

## Основные принципы

- Регистрация и вход обязательны для доступа к функциям.
- Новое QR-подключение создаёт новую сессию.
- Подключение подтверждается уже авторизованным устройством.
- QR payload содержит только короткоживущий токен подключения, не пароль и не ключи шифрования.
- Общие пакеты не зависят от React, Expo или браузерных API.
- Секреты и пользовательские данные не хранятся в Git.
- Приоритет — бесплатная инфраструктура на первом этапе, без компромиссов в базовой безопасности.

## Локальный запуск

Требования: Node.js 22.13+, pnpm 10+.

```bash
pnpm install
pnpm dev:web
```

Android:

```bash
pnpm install
pnpm dev:android
```

Проверки:

```bash
pnpm typecheck
pnpm build
```

Переменные окружения перечислены в корневом `.env.example`. Для Web Vite читает корневой файл окружения; для Android скопируй нужные `EXPO_PUBLIC_*` значения в `apps/android/.env`. В клиентские переменные допускается помещать только публичные значения. Service role keys, private keys и другие секреты запрещено добавлять в клиентское окружение.

## Текущий статус

Сейчас готовы:
- монорепозиторий pnpm + Turborepo;
- отдельные приложения Web и Android;
- начальные маршруты и экраны, включая избранные беседы;
- общие пакеты domain, protocol, validation и crypto contracts;
- базовый CI для сборки Web-клиента.

Пока не готовы:
- Supabase Auth и БД;
- серверный API и координация устройств;
- QR pairing и подтверждение;
- WebRTC/relay транспорт;
- E2EE и управление ключами;
- передача, хранение и очистка файлов;
- полноценные тесты и релизная сборка Android.
